Ce dossier est copié tel quel à la racine du site publié.

Mets-y les fichiers que les organisateurs doivent pouvoir télécharger :

- `presskit.pdf` et `technical-rider.pdf` — générés par `./build.sh`, à copier ici pour qu'ils partent en ligne (l'hébergeur ne sait pas les fabriquer, il n'a pas de navigateur).
- `photos-hd.zip` — le dossier de photos haute définition, si tu ne l'héberges pas ailleurs.

Les liens vers ces fichiers viennent de `rider_url` et `pdf_url` dans `content.json`. Laisse ces champs vides tant que les fichiers ne sont pas là : les boutons disparaissent au lieu de pointer dans le vide.

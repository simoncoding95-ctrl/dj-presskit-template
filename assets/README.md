# Assets

| Dossier | Contenu | Specs |
|---|---|---|
| `photos/` | Photos de presse | JPG, 2000 px de large minimum, paysage 3:2 pour la photo principale, sans texte ni logo incrusté. Nomme les fichiers `press-01.jpg`, `press-02.jpg`… |
| `logos/` | Logo ou typo du projet | PNG à fond transparent **et** SVG. Version claire + version sombre. |
| `artwork/` | Pochettes de sorties | JPG carré 3000×3000 si tu les diffuses. |

Garde une version haute définition ailleurs : ce dossier sert au rendu du presskit, pas d'archive.

Les photos livrées à la presse doivent être libres de droits pour un usage promotionnel, avec crédit photographe obligatoire. Vérifie ton accord avec le photographe avant de les mettre en téléchargement.
